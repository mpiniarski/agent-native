# F6 — Search

<!-- status: todo -->

## What it is

**Search** is a global overlay for quickly opening [F1 tasks](./f1-tasks.mdx), [F3 projects](./f3-projects.mdx), and saved [F5 views](./f5-views.mdx). Results update as the user types, without leaving the current screen.

Search uses **titles and names only** — not [custom field](./f2-custom-fields.mdx) values. Not-ready [inbox items](./f4-inbox.mdx) are excluded.

## What users can do

- **Open** search from a global entry.
- **Find tasks** by title.
- **Find projects** by name.
- **Find saved views** by name.
- **Open** a result to navigate to it.
- **Close** search to return to the unchanged screen underneath.

## How it behaves

- **Substring match**, case-insensitive — "report" finds "Draft Q2 report".
- Results appear directly below the search input in separate sections:
  - **Tasks** — incomplete and completed tasks whose title matches the query.
  - **Projects** — matching project names.
  - **Views** — matching saved-view names.
- Empty sections are omitted.
- Completed tasks appear alongside incomplete tasks with their completed state shown visually.
- Search is global regardless of the current page.
- Project-scoped tasks and views show their project name so duplicate titles remain distinguishable.
- Selecting a result closes the overlay:
  - A **task** result opens the main task view with that task selected.
  - A **project** result opens the project.
  - A **view** result opens that saved view in its global or project scope.
